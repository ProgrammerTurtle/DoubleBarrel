# DoubleBarrel HotEnd

DoubleBarrel is a **high-flow**, **ultra-long-meltzone** 3D printer hotend for my **high performance** custom builds, mainly [Quantumania](https://github.com/ProgrammerTurtle/Quantumania).

With an 80mm meltzone and dual 80mm long mains heater cartridges, totaling a whopping 240 watts, this is a hotend that will heat up in no time and maintain higher flow than *almost* any existing extruder can handle. **Almost**.
