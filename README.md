# DoubleBarrel
DoubleBarrel is a high-flow, ultra-long-meltzone 3D printer hotend for my high performance custom builds, mainly Quantumania.

With an 80mm meltzone and dual 80mm long mains heater cartridges, this is a hotend that will heat up in no time and maintain higher flow than *almost* any existing extruder can handle. Almost.
